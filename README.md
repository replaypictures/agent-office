# ReplayPictures AI Agent Office 🏢

3D interactive miniature workspace for ReplayPictures AI Agents (Pickle, Muse, Genspark, ChatGPT).

- Built with Three.js & OrbitControls
- 360° interactive camera orbit & zoom
- Clickable agent workstations with status cards & speech bubbles
- Mid-century modern aesthetics with customized lighting
- Dark / Light mode toggle
